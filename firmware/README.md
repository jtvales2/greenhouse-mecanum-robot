# Firmware

This directory contains the embedded firmware used by the greenhouse mecanum robot.

## Current Firmware

- MCU: STM32F407ZGT6
- Four-wheel mecanum chassis control
- Wheel-speed closed-loop control
- Encoder odometry
- IMU yaw integration
- ROS 2 serial communication protocol
